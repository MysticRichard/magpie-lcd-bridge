# 功能规格：可勾选的额度展示

## 目标

让用户在托盘设置窗口中读取 Magpie 当前配置的额度供应商和窗口，并勾选要显示在 LCD 上的内容，不再需要手工复制供应商 ID 和窗口名称。

## 用户场景

- 用户打开设置窗口，看到 Magpie `/v1/magpie/quotas` 返回的所有非空额度供应商及其窗口。
- 用户勾选最多两个供应商，每个供应商最多三个窗口。
- 保存后生成本机 `config.json`；运行中的 worker 在安全时立即重启并读取新配置。
- Magpie 暂时不可用时，窗口显示错误，已有选择不会被清空或覆盖。

## 功能需求

- FR-001：设置窗口必须通过本机 `http://127.0.0.1:3425/v1/magpie/quotas` 读取额度选项。
- FR-002：选项必须按供应商分组，并显示供应商标题、窗口名称和短标签。
- FR-003：重复的供应商记录必须按供应商 ID 合并，空窗口供应商不参与选择。
- FR-004：保存时必须限制为至少一个窗口、最多两个供应商、每个供应商最多三个窗口。
- FR-005：保存必须原子写入本机 `config.json`，且不得写入用户身份、邮箱或 BLE 地址。
- FR-006：读取 Magpie 失败时不得覆盖现有 `config.json`。
- FR-007：现有 60 秒默认刷新、BLE 协议、渲染布局和 `ble_lease.py` 不改变。
- FR-008：设置窗口和保存结果中的额度窗口按短周期优先排列为 `5 hours → 7 days → Month`；带名称前缀的窗口按前缀分组后应用相同顺序。
- FR-009：保存成功使用窗口内非阻塞状态提示；保存执行期间禁止重复触发。

## 验收标准

- SC-001：使用固定 Magpie JSON 能解析出供应商和窗口，并保留现有配置中的短标签。
- SC-002：勾选结果能生成合法的 `quota_groups` 配置。
- SC-003：超过两个供应商或每组三个窗口时给出明确错误。
- SC-004：读取失败时原配置文件字节不变。
- SC-005：自动测试、语法检查、配置检查和敏感信息扫描通过。
- SC-006：即使 Magpie 返回 `7 days` 在 `5 hours` 之前，保存后的窗口顺序仍为 `5 hours`、`7 days`、`Month`。
- SC-007：连续点击或键盘触发保存不会叠加确认对话框，成功后窗口保持可操作并显示“设置已保存”。

## 不包含

- 模型请求明细、路由访问历史或实时告警。
- 修改屏幕容量，增加第三行额度卡或每行第四个圆环。
- 自动重启 Magpie、修改 Magpie 配置或访问账号凭据。
