# 功能规格：桌面快捷方式

## 目标

为用户提供固定、可找回的 Magpie LCD Bridge 桌面入口。快捷方式既能启动控制器，也能在控制器已运行时直接打开设置。

## 功能需求

- FR-001：控制器设置窗口提供“创建桌面快捷方式”按钮。
- FR-002：执行 `install-controller-autostart.ps1` 时自动创建或更新桌面快捷方式。
- FR-003：快捷方式启动控制器时携带 `--open-settings`，首次启动后直接打开设置。
- FR-004：控制器已经运行时，点击快捷方式只打开现有控制器的设置窗口，不创建第二个实例。
- FR-005：重复创建快捷方式时覆盖同一个 `Magpie LCD Bridge.lnk`，不产生多个桌面入口。
- FR-006：卸载控制器自启时移除该快捷方式。
- FR-007：快捷方式使用项目现有 `.venv\Scripts\pythonw.exe` 和控制器脚本，不新增运行时依赖。
- FR-008：快捷方式使用项目内的 `assets\magpie-lcd.ico`，不显示默认空白或 Python 图标。
- FR-009：托盘右键菜单提供“创建桌面快捷方式”入口。

## 验收标准

- SC-001：快捷方式目标、参数和工作目录指向实际部署仓库。
- SC-002：设置窗口可以异步重建快捷方式，失败时显示窗口内状态且不冻结界面。
- SC-003：安装脚本包含共享快捷方式脚本调用。
- SC-004：自动测试、PowerShell 解析、语法检查和实际快捷方式创建通过。
- SC-005：用户点击快捷方式确认可启动控制器或打开设置。
- SC-006：实际快捷方式的 `IconLocation` 指向项目图标文件。

## 不包含

- 打包独立 EXE。
- 用户自选图片或图标主题。
- 自动固定到任务栏或开始菜单。
- 修改默认刷新间隔、BLE 协议或额度显示布局。
