# DA14585 BLE 图片协议

这是对随设备提供的 `DA LCD Studio` 控制器行为的脱敏记录，用于说明桥接程序如何复用既有固件协议。

- 屏幕：320 × 240 TFT LCD
- 主控：DA14585
- BLE 图片特征：`0000ff01-0000-1000-8000-00805f9b34fb`
- 图片命令：`image_begin=176`、`image_data=177`、`image_end=178`
- 编码：RGB565，自动选择原始、PackBits、行差分 + PackBits
- 起始包：`<HHBBII`，包含宽度、高度、格式、字节宽度、负载长度和 CRC32
- 数据包：序号加最多 156 字节负载
- 结束包：CRC32 加最终序号
- 数据写入确认：起始包和结束包确认；图片数据按 12 包窗口确认一次

该项目不修改固件、不执行 OTA，也不上传设备识别信息。
