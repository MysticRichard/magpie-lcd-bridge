# 适用场景、条件和限制

本文说明这个项目实际适配的范围。它不是通用的 LCD 驱动，也不是 Magpie 官方功能。

## 1. 已验证的硬件

当前已验证目标：

| 项目 | 实测值 |
| --- | --- |
| 设备 | `DA-LCD-772D` |
| 屏幕 | 2.4 英寸 TFT 彩色液晶屏 |
| 分辨率 | 320×240 |
| 主控 | DA14585 |
| 连接 | Windows BLE |
| 图片特征 | `0000ff01-0000-1000-8000-00805f9b34fb` |
| 协议 | 图片起始、数据、结束和 CRC 校验 |

项目通过现有固件的图片传输特征发送画面，不修改固件，不执行 OTA。

## 2. 硬件适配条件

设备必须满足以下条件才可能工作：

1. 屏幕逻辑分辨率为 320×240。
2. 设备通过 BLE 广播名称以 `DA-LCD-` 开头，或可以用命令行 `--address` 指定。
3. 设备提供图片特征 `0000ff01-0000-1000-8000-00805f9b34fb`。
4. 固件接受项目记录的图片命令、RGB565 编码和 12 包确认节奏。
5. 同一时间只允许一个 BLE 客户端连接。

其他 DA14585 设备即使主控相同，也可能使用不同的 BLE 特征、分辨率或图片协议。当前没有对其他型号做兼容性验证。

## 3. 软件条件

### 必需

- Windows。
- 可用的 BLE/WinRT 蓝牙栈。
- Python 3.11–3.14，推荐使用项目固定的 Python 3.12。
- `bleak` 和 `pillow` 依赖，执行 `uv sync` 安装。
- Windows 中文字体 `msyh.ttc`、`msyhbd.ttc` 和 `segoeuib.ttf`。
- Magpie 正在运行。
- Magpie 本地接口默认位于 `http://127.0.0.1:3425`。

### 当前未支持

- macOS。
- Linux 桌面。
- WSL 内的 BLE 访问。
- Android 或 iOS。
- Windows 服务模式。
- 多用户同时运行同一计划任务。
- 无 Magpie 的纯手动数据输入。

## 4. 数据条件

项目读取 Magpie 的两类本地数据：

- `/v1/magpie/usage?period=today`
- `/v1/magpie/quotas`

显示字段包括：

- `input`
- `output`
- `cache_read`
- `cache_write`
- `cost`
- `unpriced`
- 供应商额度窗口的 `remaining`

如果 Magpie 的接口字段、供应商 ID 或窗口名称变化，额度可能显示为短横线。此时需要更新 `config.json`，不能假定旧窗口名称继续有效。

## 5. 适合的使用场景

### 5.1 桌面常驻 AI 用量屏

电脑桌面上放一块小屏，长期显示今日 Token、费用、缓存命中率和两组额度。适合工作电脑长期开机、Magpie 常驻运行的场景。

### 5.2 作为原厂电脑资源监控的替代画面

设备原厂控制器可以显示 CPU、内存、显卡等资源。本项目不显示这些数据，而是显示 Magpie AI 用量。需要电脑资源监控时，停止桥接后打开 DA LCD Studio。

### 5.3 不希望在桌面常驻控制台窗口

安装计划任务后，程序使用 `pythonw.exe` 隐藏运行。适合不希望看到终端窗口、但希望屏幕持续更新的用户。

### 5.4 本地隐私优先

程序只读取本机 Magpie 接口，不上传数据，不读取 Magpie 账号或密钥。适合不希望把用量数据发送到第三方屏幕云服务的用户。

### 5.5 低频状态展示

默认每 60 秒更新一次，适合观察今日累计趋势和额度剩余，不适合监控秒级请求、实时告警或逐次调用。

## 6. 不适合的使用场景

### 6.1 路由访问监控

当前版本没有读取路由器、代理、Clash、OpenWrt 或其他网络设备的能力。屏幕不会显示路由访问情况。

### 6.2 多屏同时显示

当前程序按单设备、单 BLE 连接设计。多台设备需要额外的地址管理和多实例运行方案，当前自启脚本没有提供该功能。

### 6.3 历史图表和趋势分析

程序只显示当前画面，不保存历史曲线，也不提供网页仪表盘。

### 6.4 秒级实时刷新

默认间隔是 60 秒；BLE 传输本身通常需要数秒。额度变化不会立即出现在屏幕上。

### 6.5 脱离 Magpie 使用

当前没有独立采集 Codex 或 OpenCode 账号额度的实现，也没有手工录入模式。Magpie 是必需的数据源。

### 6.6 修改固件或 OTA

项目不提供固件编译、刷写或升级功能。运行期间不建议升级固件，升级后需要重新确认 BLE 特征和图片协议。

## 7. 运行生命周期

### 登录自启

计划任务只在当前 Windows 用户登录后启动。它不是开机即运行的系统服务；登录前屏幕不会被本程序刷新。

### 设备断电

设备断电后 BLE 连接会断开。程序保留重连逻辑，设备重新上电后会在后续重试周期中尝试连接；连接恢复时间取决于设备广播、Windows 蓝牙状态和刷新间隔。

### DA LCD Studio 占用

DA LCD Studio 和本桥接程序不能同时连接设备。需要原厂资源监控时，先停止桥接，再打开原厂软件。

### Windows 睡眠

当前没有专门的睡眠唤醒或自动恢复测试。电脑从睡眠恢复后，建议检查：

```powershell
.\scripts\status-magpie-lcd.ps1
Get-Content .\logs\magpie-lcd.log -Tail 30
```

## 8. 已知限制和未验证项

- 没有在其他 DA-LCD 型号、其他固件或其他 Windows 版本上完成兼容性矩阵。
- 没有验证 BLE 断开后屏幕长期保留最后一帧。
- 没有完成完整的 Windows 注销/重新登录实机验收。
- 没有完成多小时连续断线、反复断电的长期稳定性验收。
- 没有托盘图标、开机前服务、系统级多用户支持。
- 没有路由状态、历史曲线、告警推送或多页面轮播。
- 多设备场景只能通过命令行地址参数做基础尝试，自启脚本尚未提供多设备配置。

## 9. 验收建议

首次部署时按以下顺序检查：

1. `render` 能生成正确的本地预览。
2. `scan` 能找到目标设备。
3. `push` 能让实体屏显示一帧。
4. `run --interval 60` 能保持画面并周期刷新。
5. `install-autostart.ps1` 创建隐藏计划任务。
6. `status` 显示 `Running`。
7. 日志出现成功发送记录。
8. 注销并重新登录后，计划任务仍能自动启动。
9. 设备断电再上电后，观察是否恢复。

只有第 1–7 项通过，才说明本地基本链路可用；第 8–9 项属于实际环境验收，不能用单元测试代替。

## 10. 安全边界

- 不提交 `config.json`。
- 不提交真实蓝牙地址。
- 不提交 `last-frame.png` 和日志。
- 不在仓库中保存账号、Cookie、令牌或 API 密钥。
- 不将本项目描述为原控制器、固件或硬件的官方实现。
