# 实机图片说明

本目录保存项目作者提供的实体设备照片，用于说明硬件形态和运行状态。

## `device-dashboard-prototype.jpg`

- 内容：DA-LCD 设备显示 Magpie 今日 Token、参考费用、缓存命中率和额度圆环。
- 来源：项目作者的实机拍摄。
- 处理：裁除设备右侧的条码/标识区域后加入仓库。
- 状态：开发阶段版本，不代表当前代码的最终字号、圆环尺寸和间距。
- 隐私：画面不包含 Magpie 账号、邮箱、蓝牙地址或密钥。

## `device-clock-mode.jpg`

- 内容：BLE 断开后设备回到固件自带的时钟模式。
- 来源：项目作者的实机拍摄。
- 处理：裁除右侧多余画面，并对设备侧边窄条码区域做模糊处理。
- 状态：用于说明设备断线行为，不代表 Magpie 页面。
- 隐私：没有可读的账号、蓝牙地址或密钥。

当前代码的实际画面应以本地 `render` 命令生成的 `last-frame.png` 为准。
